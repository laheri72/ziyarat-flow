## 2024-05-14 - Fix O(N^2) `.filter().length` in `.sort()` comparator
**Learning:** Calling array iteration methods like `.filter().length` inside a `.sort()` comparator creates an O(N^2) bottleneck, which causes significant UI lag when rendering or filtering long lists. Furthermore, executing this logic directly inside the render cycle forces it to redundantly calculate on every keystroke (e.g., search queries).
**Action:** When grouping and sorting large datasets, precompute stats like `pending`, `completed`, and `total` lengths into a lookup dictionary using `.reduce()` or a standard loop *before* sorting. Export this stats dictionary alongside the grouped list to prevent redundant length recalculations in the UI render map as well. Always memoize intermediate filtered arrays using `useMemo` to skip work entirely if dependencies haven't changed.
