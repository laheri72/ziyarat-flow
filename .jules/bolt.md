## 2024-05-11 - [React performance optimizations]
**Learning:** Using `React.memo` effectively requires ensuring that the props passed to the component are stable. In React components, passing inline functions or unstable callbacks (like `onToggle` without `useCallback`) to a memoized child component will cause the child to re-render on every parent render, completely negating the benefit of `React.memo()`. Also, remember to fix React hooks lint warnings rather than disabling them.
**Action:** When using `React.memo`, thoroughly check all props passed to the child component and ensure they are primitive values or stable object references (using `useMemo` or `useCallback`). And don't use `eslint-disable-next-line` for hook dependency warnings; instead, wrap the dependencies appropriately (e.g. `useCallback` for functions) and include them in the dependency array.
