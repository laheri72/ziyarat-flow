## 2024-05-28 - Missing React.memo on Lists and Data Manipulations
**Learning:** In React, heavy data transformations like filtering, grouping, sorting and rendering large lists are prone to bottleneck main thread performance if not memoized, particularly when inputs such as a search query update frequently. Wrapping these list rendering objects with `React.memo` (and the callback prop updates mapped to it with `useCallback`) alongside using `useMemo` on these transforms eliminates unnecessary UI re-rendering when properties have not mutated.
**Action:** When implementing filtering or search across datasets displayed in lists, ensure that the processed list values are memoized using `useMemo` and the list item components use `React.memo` to prevent re-renders of list items whose data has not changed.
