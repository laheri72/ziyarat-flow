## 2023-11-20 - React List Performance Pattern
**Learning:** In a highly dynamic list application rendering complex interactive items, failing to pair `React.memo` on list components with a stable `useCallback` function reference from the parent forces full VDOM diffing for the entire list upon a single item's update. Specifically, creating arrow functions inside a map (e.g., `onToggle={(id) => handleToggle(id, tag)}`) defeats `React.memo` entirely since the function reference changes on every render.
**Action:** When mapping over large datasets in React, strictly provide stable `useCallback` references directly to child components wrapped in `React.memo` to eliminate O(n) re-render penalties across untouched components. Ensure parent components don't re-create callbacks continuously.
