## 2024-05-18 - Memoize filteredAssignments and groupedAssignments\n**Learning:** Without memoization, `filteredAssignments` and `groupedAssignments` in Dashboard.tsx are recalculated on every render, which can be expensive with many assignments.\n**Action:** Use `useMemo` for both derivations to prevent unnecessary recalculations.
## 2024-05-18 - Memoize component derived state in Dashboard and Admin\n**Learning:** Derived state like `currentEventAssignments`, `filteredAssignments`, `groupedAssignments`, and `filteredProgress` are being recalculated on every render. Given React re-renders on status toggle, this can lead to slow UX as lists grow.\n**Action:** Use `useMemo` for derived states.
